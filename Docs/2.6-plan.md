# 2.6 Economy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เงิน (B) + ราคา + ทิป + ชื่อเสียงแบบหลอดทีละเลเวล + ระบบก่อสร้างกลาง (อัปเกรดร้าน 3 ขั้นที่เคาน์เตอร์ช่าง) + หน้าสรุปวัน + เซฟ v8

**Architecture:** `PlayerWallet` (Player) รับเงินจาก Customer/จดหมาย · `ShopProgress` (เดิม) ได้ตารางเลเวล + หลอด + ชื่อเสียงรวม · `ConstructionProject` (SO) + `ConstructionManager` นับวันตอนเช้า → effect · `BuilderCounter` → `ConstructionUI` (Yes/No) · `DaySummaryData` ดึงสถิติจาก CustomerManager/ShopProgress

**Tech Stack:** Unity 6.3, C#, uGUI + TMP, JsonUtility, Claude Sheets

**Spec:** `Docs/2.6-design.md`

## Global Constraints

- ข้อความในเกม/ชื่อ/Debug.Log อังกฤษ คอมเมนต์ไทย · .cs/CSV = UTF-8 BOM + CRLF · enum ต่อท้ายเท่านั้น · Build ใหม่ = มีแล้ว kept
- สกุลเงิน `B` รูปแบบ `B 1,250` · เงินเริ่ม 500 · หลอด 500 / 1,500 / 3,000 (Lv4 = 3,000 สูงสุด) · อัปเกรด 20,000 / 75,000 / 150,000 · 1 / 2 / 3 วัน
- ชื่อเสียง Loved +3 / Good +2 / Meh +1 / เดินออก 0 · ทิป = round(ราคา × max(0, ความพอใจ − 0.9))
- ช่าง 09:00–16:00 · สร้างทีละงาน · เปิดร้านได้ระหว่างสร้าง · Hire = กล่อง Yes/No
- ไม่มีตัวทดสอบอัตโนมัติ → ผู้ใช้ทดสอบใน Unity ตามขั้นท้ายแผน / Claude อ่าน Editor.log ได้

## Review Focus

1. **เงินไม่พอ / ของไม่ครบ / หลอดไม่เต็ม / นอกเวลาช่าง / กำลังสร้างอยู่** → Hire กดไม่ได้ + บอกเหตุผล ไม่หักอะไร (Task 6)
2. **โหลดเซฟระหว่างก่อสร้าง** → วันที่เหลือถูกต้อง เสร็จตามกำหนด ไม่หักเงินซ้ำ (Task 5)
3. **เริ่มอัปเกรดวันเดียวกับที่หลอดเพิ่งเต็ม** → จดหมายเชฟของเลเวลนั้นยังมา (BarSpent) (Task 4)
4. **ลูกค้าได้จานตอนร้านปิดไปแล้ว (Last call)** → เงิน/ชื่อเสียงยังนับวันนี้ (Task 3)
5. **เซฟ v7 เก่า** → เงิน 500, ชื่อเสียงรวม = ชื่อเสียงปัจจุบัน, ไม่มีงาน (Task 2/4/5)
