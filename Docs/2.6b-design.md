## 1. เป้าหมายและเหตุผล

- ผู้เล่นมีทางซื้อของ (วัตถุดิบที่ยังหาเองไม่ได้ เช่น เนื้อ ไข่ แป้ง ข้าว) และทางเปลี่ยนของเป็นเงินนอกเหนือจากร้านอาหาร
- **กล่องขายข้ามคืนแบบ Stardew** = ที่ระบายของที่ไม่ใช้ / จานที่ทำเกิน เงินเข้าตอนจบวัน
- **ชื่อเสียงคือตัวกั้นการอัปเกรดร้าน** (ผู้ใช้): ต่อให้ขายของได้เงินเยอะ ถ้าไม่เปิดร้านอาหารก็อัปเกรดร้านได้ช้ามาก
- ร้านทุกร้านเป็นร้าน "ซื้อเวลา": ในเกมเต็ม**ทุกวัตถุดิบหาเองได้** (ปลูกข้าว → แป้ง, ตีมอนสเตอร์/ล่าสัตว์ได้เนื้อ, ตกปลา/ดักกุ้ง, ไข่หายากในป่า) ร้านแค่ช่วยประหยัดเวลา
- สำหรับเล่นทดสอบทั้งวงจรท้ายเฟส 2 (ยังไม่ใช่เดโมจริง ของไม่ต้องครบ)

**ไม่ใช่เป้าหมาย (2.6b):** NPC เจ้าของร้าน, ของหมุนเวียน/ของนอกฤดู/พ่อค้าเร่, เมล็ดพันธุ์และระบบปลูก, ขายออนไลน์ผ่านคอม, ราคาตามความยาก (★)

**สิ่งที่ห้ามเกิด:** มีช่องปั๊มเงิน (ซื้อแล้วขายคืนได้กำไร) / กล่องขายให้ชื่อเสียงเท่าหรือมากกว่าการเปิดร้าน / ขายของได้ระหว่างเปิดร้านอาหาร / ของหายเพราะกระเป๋าเต็ม

## 2. กฎเศรษฐกิจ (ตัดสินแล้ว)

| เรื่อง | กฎ |
|---|---|
| ขายให้กล่อง / ร้านของชำ | **100% ของ `ItemData.sellPrice`** (วัตถุดิบ = ราคาวัตถุดิบ, จาน = ราคาเมนู) |
| คุณภาพจานตอนขาย | **OK ×1.0 / Good ×1.1 / Perfect ×1.25** (ปัดเป็นจำนวนเต็มต่อชิ้น) / จานไม่ระบุคุณภาพ = Good |
| ร้านขายให้ผู้เล่น | **×2 ของ `sellPrice`** ทุกอย่าง → ซื้อแล้วขายคืนขาดทุนเสมอ |
| ของที่ขายได้ | `sellPrice` > 0 เท่านั้น (อุปกรณ์/เครื่องประดับที่ยังเป็น 0 ขายไม่ได้) |
| ชื่อเสียงจากการขายจาน | จานที่ขาย (**กล่อง + ร้านของชำนับรวม**) ทุก 5 จานในวันเดียวกัน = **+2** / ไม่สะสมข้ามวัน / **สูงสุด +10 ต่อวัน** / วัตถุดิบดิบไม่ได้ชื่อเสียง |
| ราคาตามความยาก ★ | **ไม่เอาไปก่อน** (ทบทวนตอนเล่นทดสอบทั้งวงจร) |

- ตัวอย่าง: วันนี้ขาย 4 จาน = 0 / พรุ่งนี้ 1 จาน = 0 / ขาย 12 จาน = +4 / ขาย 40 จาน = +10
- ชื่อเสียงจากการขายคิด**ตอนจบวัน**ครั้งเดียว (ของในกล่องเอาคืนได้จนกว่าจะนอน) ผ่าน `ShopProgress.AddReputation` → เข้าหลอดเหมือนชื่อเสียงจากลูกค้า (หลอดเต็มแล้วหยุด ตามกฎ 2.6)
- เทียบ: เปิดร้านดีๆ ≈ +20–35/วัน (ลูกค้า 13–16 คน) → กล่องช่วยได้มากสุด ~1/3

## 4. กล่องขายข้ามคืน (Shipping Box)

- วางหน้าร้านใกล้ตู้จดหมาย / ใช้ได้ทุกเวลา **ยกเว้นตอนเปิดร้านอาหารและหน้าสรุปวัน** (เหมือนกระเป๋า)
- กด E → หน้าต่างสองฝั่ง:

```
┌──────────── Shipping Box ─────────────────────────────┐
│ [Ingredients][Dishes]           │ In the box today     │
│ ┌──┐┌──┐┌──┐┌──┐┌──┐            │ Som Tam (Perfect) x5 │
│ │  ││  ││  ││  ││  │  ...       │ Tomato x12           │
│ └──┘└──┘└──┘└──┘└──┘            │ Basil x3             │
│ Som Tam  Perfect x2 Good x5     │──────────────────────│
│ Sell: [1] [5] [All]  (Perfect ▼)│ Total: B 812         │
│                                 │ Dishes: 5/25 → +2 Rep│
│                                 │ [Take back]          │
└─────────────────────────────────┴──────────────────────┘
```

- ซ้าย = ของในกระเป๋าที่ขายได้ (แท็บวัตถุดิบ/จาน) / จานเลือกคุณภาพก่อนใส่ / ปุ่ม 1 / 5 / ทั้งหมด
- ขวา = ของในกล่องวันนี้ + ยอดรวม + ตัวนับจาน/ชื่อเสียง (รวมจานที่ขายร้านของชำวันนี้ด้วย)
- **เอาคืนได้ทุกชิ้นจนกว่าจะนอน** (ต่างจาก Stardew ที่คืนได้แค่ชิ้นล่าสุด) / กระเป๋าเต็มตอนเอาคืน = คืนได้เท่าที่ใส่ได้ ที่เหลืออยู่ในกล่อง
- ใส่กล่อง = **ย้ายของออกจากกระเป๋าทันที** (กันใช้ซ้ำ) / ไม่นับเป็นการ "ค้นพบ" ใหม่ (ของที่เคยมีแล้วยังเป็นค้นพบแล้ว)
- **ตอนจบวัน** (นอนหรือสลบตี 3): ขายทุกชิ้นในกล่อง → `PlayerWallet.Add` → `DaySummaryData.OvernightIncome` / คิดชื่อเสียงจากการขาย → `ShopProgress.AddReputation` → ล้างกล่อง
- หน้าสรุปวัน: บรรทัดกล่องขายข้ามคืน (มีช่องรออยู่แล้ว) + บรรทัด/ยอดชื่อเสียงรวมชื่อเสียงจากการขายด้วย

**ร้านของชำฝั่งขาย** ใช้แผงขายชุดเดียวกัน ต่างกันที่ได้เงินทันที เอาคืนไม่ได้ ฝั่งขวาแสดงยอดที่ขายวันนี้แทน

## 5. หน้าต่างร้าน (ShopUI)

- กด E ที่เคาน์เตอร์ร้าน (ในเวลา) → หน้าต่าง: หัวร้าน + เงินที่มี + รายการซื้อ / ร้านที่รับซื้อ = มีแท็บ `Buy | Sell`
- แต่ละแถว: ชื่อ, ราคา, จำนวนที่มีในกระเป๋า, ปุ่ม `Buy 1` / `Buy 5` (ไอเทม) / `Buy` (กระเป๋า, สมุด)
- ซื้อไม่ได้ = ปุ่มจาง + เหตุผลสั้น (`Not enough money` / `Bag full (150)` / `Learned` / `Max level`)
- ซื้อไอเทม: เช็กเงินและที่ว่างในกระเป๋าก่อน (ซื้อทั้งหมดหรือไม่ซื้อเลย เหมือน `Inventory.AddItem`) / ซื้อ 5 แต่ที่ว่างเหลือ 3 = ปุ่มซื้อ 5 ใช้ไม่ได้
- ระหว่างเปิดหน้าต่างร้าน/กล่อง: นาฬิกาหยุด เดินไม่ได้ เปิดกระเป๋าไม่ได้ ใช้ Hotbar ไม่ได้ (แบบหน้าต่างช่าง/จดหมาย) / Esc หรือปุ่ม Close ปิด
- ข้อความในเกมเป็นภาษาอังกฤษ ไอคอนยังเป็นสี่เหลี่ยม

- `Inventory.cs`: ค่าตั้งต้น `stackCapsByLevel = {30, 150, 500}` (**ค่าในฉากเป็น {30,99,300,999} → ตัว Build ต้องแก้ใน Inspector ให้ด้วย**) / ต้องรองรับของเกินเพดานตอนโหลดเซฟเก่า (ตอนนี้ `SetItems` ไม่ตัดอยู่แล้ว = ใส่เพิ่มไม่ได้จนกว่าจะลดลง)
- `DayEndManager.cs`: เรียก `SalesLedger` ตอนจบวัน ใส่ `OvernightIncome` + ชื่อเสียงจากการขาย
- `DaySummaryUI.cs`: แสดงชื่อเสียงจากการขายแยกบรรทัด (ถ้ามี)
- กันเปิดหน้าต่างซ้อน: ทุกจุดที่เช็ก `ConstructionUI.IsAnyOpen` (BuilderCounter, Mailbox, MailDesk, PlayerActionController, InventoryUI) ให้เช็ก `ShopUI.IsAnyOpen` / `ShippingBoxUI.IsAnyOpen` ด้วย
- ราคาจาน: `ItemData.sellPrice` ของจาน = `RecipeData.sellPrice` (ตัว import ตั้งให้) = ราคาที่ลูกค้าจ่าย → ใช้ตัวเดียวกันได้
- `RecipeBook` Debug ที่อัปเกรดกระเป๋าให้เอง ใช้ได้ต่อ (ระดับสูงสุดเป็น 3)

**เซฟ:** **ไม่ต้องเพิ่มเวอร์ชัน** — เกมเซฟตอนจบวันเท่านั้น (`OnDayEnded`) ตอนนั้นกล่องถูกขายและล้างแล้ว ตัวนับจานรายวันก็รีเซ็ต / เซฟเก่าที่กระเป๋าระดับ 4 → `SetBagLevel` ตัดเป็น 3 เอง

**Debug:** SalesLedger คลิกขวา `Print Status` / `Sell Box Now` (ทดสอบไม่ต้องนอน) / ร้านเปิดนอกเวลาได้ด้วยติ๊ก `Ignore Hours` ที่เคาน์เตอร์
