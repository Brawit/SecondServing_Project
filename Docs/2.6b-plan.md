# 2.6b Shops + Shipping Box Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ร้านค้า 3 ร้าน (ของชำ ซื้อ/ขาย · กระเป๋า · หนังสือ) + กล่องขายข้ามคืนแบบ Stardew + ชื่อเสียงจากการขายจาน + กระเป๋า 3 ระดับ + สมุดสูตร 9 เล่ม

**Architecture:** `SalesLedger` (singleton) = ราคาขาย/ขายตรง/กล่อง/ตัวนับจานรายวัน/ปิดยอดตอนจบวัน · `ShopCatalog` (SO) + `ShopPurchase` (static) = รายการและการซื้อ · `ShopKeeperCounter` / `ShippingBox` (IInteractable) → `ShopUI` / `ShippingBoxUI` ที่ใช้ `SellPanelUI` ร่วม · `DayEndManager` เรียก `SalesLedger.SettleDay` · `Tools > Build Shops` สร้างทุกอย่าง

**Tech Stack:** Unity 6.3, C#, uGUI + TMP, Claude Sheets

**Spec:** `Docs/2.6b-design.md`

## Global Constraints

- ข้อความในเกม/ชื่อ/`[Header]`/Debug.Log อังกฤษ คอมเมนต์ไทย · .cs/CSV = UTF-8 BOM + CRLF · enum ต่อท้ายเท่านั้น · Build ใหม่ = มีแล้ว kept · ส่งโค้ดครบทั้งไฟล์ · บอกชื่อไฟล์ที่เปลี่ยนทุกไฟล์
- ขาย = 100% `sellPrice` × คุณภาพจาน (OK 1.0 / Good 1.1 / Perfect 1.25, ปัดลงต่อชิ้น, ไม่ใช่จาน = ×1) · ขายได้เมื่อ `sellPrice > 0`
- ซื้อ = `sellPrice` × 2 · สมุด = ราคาจาน × 10 · กระเป๋า Lv2 B 2,500 / Lv3 B 20,000 · เพดาน {30, 150, 500}
- ชื่อเสียงจากการขาย = min(10, floor(จานที่ขายวันนี้ (ร้าน + กล่อง) / 5) × 2) คิดตอนจบวัน · วัตถุดิบไม่นับ
- ร้าน 09:00–17:00 · ไม่จำกัดจำนวน · ใช้ร้าน/กล่องไม่ได้ระหว่างเปิดร้านอาหารและหน้าสรุปวัน · หน้าต่างเปิด = นาฬิกาหยุด เดินไม่ได้
- ไม่เพิ่มเวอร์ชันเซฟ (เซฟตอนจบวันหลังปิดยอดกล่องแล้ว)
- ไม่มีตัวทดสอบอัตโนมัติ / Claude ไม่มีตัวคอมไพล์ → ผู้ใช้ทดสอบใน Unity ตาม Task 7 / Claude อ่าน Editor.log ได้

## Review Focus

1. **กระเป๋าเต็มตอนซื้อหรือเอาของคืนจากกล่อง** → ซื้อไม่ได้ + `Bag full (150)` ไม่หักเงิน / เอาคืนได้เท่าที่ใส่ได้ ที่เหลืออยู่ในกล่อง (Task 2, 5)
2. **ใส่กล่องแล้วสลบตี 3** → กล่องยังขาย เงิน + ชื่อเสียงขึ้นหน้าสรุป (Task 3)
3. **นับจานข้ามวัน / รวมสองช่องทาง** → 4 วันนี้ + 1 พรุ่งนี้ = 0 · ร้าน 3 + กล่อง 2 = +2 · 12 = +4 · 40 = +10 (Task 2)
4. **เซฟเก่ากระเป๋าระดับ 4 / ของเกิน 150** → ระดับ 3 ของไม่หาย ใส่เพิ่มไม่ได้จนลดลง (Task 2)
5. **กด E ที่ร้าน/กล่องตอนเปิดร้านอาหาร หน้าสรุป หรือหน้าต่างอื่นเปิดอยู่** → ไม่เปิด ไม่ซ้อน (Task 4, 5)
