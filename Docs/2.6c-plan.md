# 2.6c Forest Test Area – แผนการทำ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เมนู `Tools > Second Serving > Build Forest Test Area` สร้าง prefab ของป่า 13 ชิ้น + ทาสีแผนที่ป่าใต้บ้าน + สร้างโซนงอก 4 โซน ในการกดครั้งเดียว

**Architecture:** ไฟล์ Editor เดียว `Assets/Scripts/Editor/ForestAreaBuilder.cs` (static class แบบ ShopSetupBuilder) แยกเป็น 3 เมธอด: EnsurePrefabs → PaintMap → EnsureZones ไม่แตะสคริปต์ runtime

**Tech Stack:** Unity 6.3, UnityEditor (PrefabUtility, Undo, SerializedObject, Tilemap.SetTile)

**Spec:** `Docs/2.6c-design.md`

## Global Constraints
- `[Header]` / ชื่อ / Debug.Log อังกฤษ คอมเมนต์ไทย / ไฟล์ .cs = UTF-8 with BOM + CRLF / เขียนครบทั้งไฟล์
- กดซ้ำได้: prefab ที่มี = kept, โซนชื่อเดิม = kept, ทาสี tile ผลเท่าเดิม / ทุกอย่างอยู่ใน Undo group เดียว + MarkSceneDirty
- Tilemap หาจากชื่อ `Ground`, `Obstables`, `CameraBoundsMap` / tile `Assets/Tiles/Grass|Dirt|Wall|Bound.asset`
- ไม่มี Unity ฝั่ง Claude → โค้ดยังไม่ได้คอมไพล์ ผู้ใช้ทดสอบเอง

## Review Focus
1. ไม่เจอ Tilemap/tile/ItemData ตัวใดตัวหนึ่ง → ต้องรายงานใน report แล้วทำส่วนที่ทำได้ต่อ ไม่ throw
2. กดซ้ำหลังผู้ใช้จูนโซนแล้ว → ค่าในโซนต้องไม่ถูกทับ
3. CameraBoundsMap ต้องต่อเป็นก้อนเดียว (กว้าง ≥ ลานเดิมทุกแถว) ไม่งั้นกล้องกระโดด
4. TilemapCollider2D / CompositeCollider ของ CameraBoundsMap ต้องอัปเดตหลัง SetTile → แจ้ง Confiner ด้วย `InvalidateBoundingShapeCache()` ถ้าหาเจอ
5. โซนต้องเป็นลูกของ ForageSpawner (ไม่งั้น spawner ไม่เห็น)
