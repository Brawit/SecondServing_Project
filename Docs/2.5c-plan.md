# 2.5c Chef Mail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** สูตรปกติได้จากจดหมายเชฟเมื่อเลเวลร้าน + ชื่อเสียงถึงเกณฑ์ จดหมายมาตอนเช้า อ่านซ้ำได้ + วางข้อมูลทางได้สูตรทุกทางไว้ให้เฟส 3

**Architecture:** ข้อมูลมาจากตาราง (Recipes + ชีต Chefs) ผ่านตัว import เดิม → `RecipeData` / `ChefData` / `ShopProgress` (เลเวล+ชื่อเสียง) / `MailSystem` เช็กตอน `OnDayStarted` → `Mailbox` (IInteractable) เปิด `MailUI` → อ่านครั้งแรก = `RecipeBook.Learn` (แจ้งเตือนอยู่แล้วในตัว) / เซฟ v7

**Tech Stack:** Unity 6.3, C#, uGUI + TextMeshPro, JsonUtility save, Claude Sheets (Claude Docs connector)

**Spec:** `Docs/2.5c-design.md`

## Global Constraints

- ข้อความในเกม, `[Header]`, ชื่อตัวแปร/คลาส, `Debug.Log` = อังกฤษ / คอมเมนต์ = ไทย
- ไฟล์ `.cs` และ CSV = UTF-8 with BOM + CRLF / เขียนโค้ดครบทั้งไฟล์
- enum ต่อท้ายเท่านั้น / หัวคอลัมน์ตารางห้ามเปลี่ยนชื่อ
- เครื่องมือ Build ใหม่: มีอยู่แล้ว = ไม่ทับ (kept)
- `maxLettersPerMorning` = 2 / เลเวลเริ่ม 1 ชื่อเสียงเริ่ม 0
- ไม่มีตัวทดสอบอัตโนมัติ (ไม่มี Unity Test Framework, ฝั่ง Claude คอมไพล์ไม่ได้) → **การทดสอบทุกงาน = ผู้ใช้เปิด Unity ดู Console ไม่มี error แล้วทำตามขั้นทดสอบในงานนั้น** / Claude อ่าน `Editor.log` ช่วยหา error ได้
- หลังเขียนไฟล์บนเครื่องผู้ใช้: เทียบ `md5sum` + บอกชื่อทุกไฟล์ที่เปลี่ยน

## Review Focus

1. **เลิกเล่นกลางวันโดยไม่นอน** หลังอ่านจดหมาย → โหลดใหม่ จดหมายต้องมาใหม่ (ยังไม่อ่าน) และสูตรยังไม่รู้ ไม่ใช่จดหมายหายหรือสูตรค้าง → ทดสอบใน Task 4
2. **สูตร Chef Mail ที่รู้อยู่แล้ว** (Debug Learn All / เซฟเก่า) → ไม่ส่งจดหมายฉบับนั้น และ `Deliver All Chef Letters` ก็ข้าม → Task 4
3. **เซฟเก่า v6** → โหลดได้ เลเวล 1 ชื่อเสียง 0 ไม่มีจดหมาย → Task 3/4
4. **เปิดหน้าต่างจดหมายซ้อนกับหน้าต่างอื่น** (กระเป๋า, เมนู, เตา, ระหว่างเปิดร้าน, หน้าสรุปวัน) → เปิดไม่ได้ / ระหว่างเปิด MailUI ใช้ของอื่นไม่ได้ → Task 5
5. **เนื้อจดหมายยาว/หลายบรรทัด/มีจุลภาค** ใน CSV → import ครบทั้งข้อความ ข้อความยาวเลื่อนอ่านได้ → Task 1/2/5

### Task 4: MailSystem + เซฟจดหมาย

- Create: `Assets/Scripts/Mail/MailSystem.cs`
- Modify: `SaveData.cs`, `SaveManager.cs`

**Interfaces:**
