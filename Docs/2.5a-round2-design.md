# ขั้น 2.5a รอบ 2 — เตา + มินิเกม + ถือจาน (แบบร่าง)

> เขียน 23 พ.ย. 2026 / ผู้ใช้เลือกทาง A + ขั้นตอนเฉพาะสูตร + ช่องภาพต่อขั้นตอน

## เป้าหมาย
ให้การเปิดร้านมีเฟสทำอาหารจริงจังแบบ Dave the Diver: ทำที่เตา → มินิเกมสั้นๆ → ได้จาน OK/Good/Perfect → ถือไปเสิร์ฟ
แต่ละเมนูให้ความรู้สึกต่างกันได้ทั้งที่มีมินิเกมแค่ 3 แบบ และพอมีภาพแล้วต้องผูกภาพได้ไม่มั่ว

## สิ่งที่ผู้ใช้ตัดสินแล้ว
- ตัดทางลัด "ไม่มีจาน = หักวัตถุดิบเสิร์ฟเลย" ออก → ตอนเปิดร้านเสิร์ฟได้แค่จานในมือ หรือจานที่ทำไว้ในกระเป๋า
- ระหว่างมินิเกม **เดินไม่ได้** ยืนที่เตา / Esc = ยกเลิก (ไม่เสียวัตถุดิบ) / เวลาร้านและความอดทนลูกค้าเดินต่อ
- ปุ่ม: Timing = Space / Mash = รัว Space / Sequence = ลูกศรหรือ WASD
- ถือจานได้ 1 จาน เฉพาะตอนเปิดร้าน / Q = เก็บเข้ากระเป๋า / ปิดร้าน = เข้ากระเป๋าเอง
- นอกเวลาร้าน: หน้าต่างรายการสูตร ทำเสร็จเข้ากระเป๋า นาฬิกาเดินปกติ
- ไม่มีหน้าต่างผลลัพธ์: แถบกระพริบสีตามผล ~0.5 วิ แล้วปิดเอง

## ทางที่พิจารณา
- **A (เลือก)** แยกชิ้น: Stove / CookingSession / มินิเกมแบบละสคริปต์ / CarriedDish / ขั้นตอนอยู่ใน asset
- B ขั้นตอนมาจากคอลัมน์ในตาราง → ไว้ทีหลังถ้าต้องการ (ตอนนี้ยังไม่จำเป็น ต้องแก้ตาราง+importer)
- รวมมินิเกมทุกแบบในสคริปต์เดียว → ตัดทิ้ง (โตแล้วแก้ยากตอนเพิ่ม Hold/Stir)

## ขั้นตอนของสูตร 3 ชั้น (ใช้ชั้นที่เจาะจงที่สุด)
1. `RecipeData.customSteps` (ไม่ว่าง) → ใช้อันนี้
2. `RecipeData.cookingProfile` (CookingProfile asset ใช้ร่วมหลายสูตร)
3. ค่าตั้งต้นตาม Course ใน `CookingSettings` (Main / Dessert / Drink)

`CookingStep` = ชนิดมินิเกม + ชื่อท่า (`Pound!`) + ภาพ (ว่างได้) + ค่าปรับ (0 = ใช้ค่าปกติใน CookingSettings)
- Timing: ความกว้างโซน, ความเร็วเข็ม, จำนวนครั้ง, โซนเลื่อน
- Mash: จำนวนครั้ง, เวลา
- Sequence: ความยาว, เวลาต่อปุ่ม
- Hold / Stir มีชื่อใน enum แล้ว (2.5b) ตอนนี้เล่นเป็น Timing / Mash แทน

## ภาพ (ไม่ให้มั่ว)
มินิเกมไม่รู้จักภาพเอง ภาพมาจากขั้นตอนที่สั่งเล่น ลำดับการหา:
1. `visual` ของขั้นตอนนั้น
2. (ขั้นตอนเฉพาะสูตร) ขั้นตอนลำดับเดียวกันใน `cookingProfile` ของสูตร ถ้าชนิดมินิเกมตรงกัน
3. ภาพตั้งต้นตามชนิดมินิเกมใน CookingSettings
4. ไม่มีเลย = สี่เหลี่ยม placeholder
ไอคอนวัตถุดิบ/จานดึงจาก `ingredients` / `dishItem` ของสูตรเอง (ใช้ตอนมีภาพ เฟส 4)

## คุณภาพ
แต่ละขั้นได้ 0 (OK) / 1 (Good) / 2 (Perfect) → เฉลี่ย ≥ 1.6 = Perfect, ≥ 0.6 = Good, ไม่งั้น OK (ปรับได้ใน CookingSettings)

## ตอนเปิดร้าน
- กด E ที่เตา → แถบเหนือเตา `< [Som Tam (2 waiting)]  Lemonade >` เฉพาะเมนูที่ยังทำได้ เรียงตามคนรอมากสุด
  - มีตัวเลือกเดียว = เริ่มทำเลย / scroll / คลิก / คลิกซ้ำหรือ E = เริ่ม / Esc หรือเดินห่าง = ปิด
- ทำได้อีก = `Remaining − จานนั้นในกระเป๋า − จานในมือ` และวัตถุดิบต้องพอ (หักวัตถุดิบที่เมนูอื่นจองไว้)
- ถือจานอยู่ = ทำใหม่ไม่ได้ (แจ้งเตือนให้เสิร์ฟหรือกด Q)
- วัตถุดิบหักตอนทำเสร็จ / `Remaining` ลดตอนเสิร์ฟเหมือนเดิม
- กด E ที่ลูกค้า: ถือจานตรง = เสิร์ฟจานในมือ / ถือไม่ตรง = "This customer ordered …" / มือว่าง = จานในกระเป๋า (แถบเลือกคุณภาพเดิม) / ไม่มีเลย = "Cook … at the stove first."
- ร้านปิดระหว่างกำลังทำ = ทำเสร็จแล้วเข้ากระเป๋า

## นอกเวลาร้าน
กด E ที่เตา → หน้าต่างสูตรที่รู้และวัตถุดิบพอ → คลิก = เริ่มมินิเกม → จานเข้ากระเป๋าพร้อมคุณภาพ
