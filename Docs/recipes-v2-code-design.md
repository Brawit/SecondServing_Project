# Recipes v2 → เข้าเกม: เอกสารออกแบบโค้ด

> 26 พ.ย. 2026 / ข้อมูลต้นทาง: ชีต `Ingredients v2` (112 แถว) + `Recipes v2` (109 แถว) ใน Claude Sheets
> การตัดสินใจด้านเกมทั้งหมดอยู่ใน `recipes-v2-design.md` เอกสารนี้เป็นเรื่อง "ทำยังไงในโค้ด" เท่านั้น
> ป้าย: **(ผู้ใช้)** = ผู้ใช้ตัดสิน / **(Claude)** = Claude ตัดสิน ผู้ใช้แก้ได้

## 1. เป้าหมาย

ผู้ใช้เล่นวงจรเต็มแล้วพบว่าต้นเกมแทบไม่มีอะไรให้ทำ ทำได้แค่เลมอนเนดกับจานหลัก 1 จาน จึงออกแบบสูตรใหม่ทั้งหมด (v2) งานนี้คือเอาข้อมูล v2 เข้าเกมให้เล่นได้จริง

- **เป้าหมาย:** เกมใช้ข้อมูล v2 ครบ: ช่องหมวด (any_fish ฯลฯ) + ผู้เล่นเลือกวัตถุดิบเอง + ราคาตามวัตถุดิบจริง + ตัวคูณดาว × คุณภาพ + Fine-dining ★4 + Stamina แบบ Stardew + ราคาเศรษฐกิจใหม่
- **ไม่ทำรอบนี้:** ระบบฤดูกาล (ไม่มีปฏิทินในเกม → เก็บข้อมูล Season ไว้เฉยๆ), ราคานอกฤดู ×5, เลี้ยงสัตว์ / เครื่องทำชีส / ถังบ่ม, cutscene และจดหมายปลด Fine-dining (ใช้ pop-up ธรรมดาไปก่อน), ภาพ (ไอคอนเงาดำใช้สีดำทับไอคอนที่มีอยู่)
- **ห้ามเกิด:** ระบบที่ผู้ใช้ทดสอบผ่านแล้วพัง (กระเป๋า เซฟ เมนูประจำวัน ลูกค้า กล่องขาย ร้านค้า) / เซฟเก่าโหลดไม่ขึ้น / มีไฟล์ไอเทมงอกเป็นร้อยใน Assets

## 2. ทางที่พิจารณา (จานแยกตามวัตถุดิบ)

| **A** ← เลือก (ผู้ใช้) | ไอเทมจานแยกต่อแบบ เช่น `jp_sushi__salmon` | ระบบเดิมมองเป็นไอเทมธรรมดา แก้น้อย | ไอเทมเยอะ (~200) |

## 4. งาน 1: ข้อมูลและช่องหมวด

### 4.1 CSV และตัว import
- Claude อ่านชีต v2 แล้วเขียน `Assets/Data/Ingredients.csv` / `Recipes.csv` ใหม่ทั้งไฟล์ (UTF-8 BOM + CRLF, python `csv`) **หัวคอลัมน์ = ชีต v2 ตรงตัว** ชีต v1 คงไว้เป็นประวัติ
- `RecipeImporter` อ่านตามชื่อหัวคอลัมน์อยู่แล้ว เพิ่ม: `In Store`, `Early`, `Type`, `Season`, `Key 5`, `Base Recipe`, Obtain `Mastery`
  - Key ที่ขึ้นต้น `any_` = ช่องหมวด (any_fish → Fish, any_vegetable → Vegetable, any_fruit → Fruit, any_cheese → Cheese)
  - Base Recipe อ่านรอบสอง (หลังสร้างสูตรครบ) เพราะชี้ไปสูตรอื่น
- **ไอเทมเก่าที่ไม่มีใน v2** (เช่น `seasonal_fruit`): ตัว import **ไม่ลบ** แค่พิมพ์รายชื่อใน Console ให้ผู้ใช้ลบเอง (Claude) / เซฟที่มีของพวกนี้ → SaveManager ข้ามพร้อมเตือนอยู่แล้ว (ของหาย ไม่ crash)
- สูตรเก่าที่ไม่มีใน v2: เหมือนกัน รายงาน ไม่ลบ / RecipeBook ที่รู้สูตรเก่าข้ามไป

### 4.2 enum (เพิ่มต่อท้ายเท่านั้น)
- `ItemCategory` + Mushroom, Fish, Shellfish, Egg, Legume, Spice, Processed, Import, Seaweed, Cheese, AgedCheese (Herb Vegetable Fruit Nut Meat Grain Dairy Sweetener มีอยู่แล้ว)
- `ItemSource` + Garden, Ranch, Hunt, Processed, Import (Forage Sea มีอยู่แล้ว)
- ใหม่ `ItemOriginType` (คอลัมน์ Type): Forage, FruitTree, Crop, Fish, CrabPotBeach, AnimalProduct, MonsterLoot, Artisan, Import
- ใหม่ `[Flags] Season`: Spring 1, Summer 2, Fall 4, Winter 8 (All = 15)
- `RecipeSource` + Mastery

### 4.3 ItemData เพิ่มช่อง
`inStore` (bool), `earlyGame` (bool), `originType`, `seasons` — ตัว import เขียน / ไม่ทับ icon description เหมือนเดิม

### 4.4 RecipeData
- `ingredients` (List<ItemData>) → **`slots` (List<RecipeSlot>) สูงสุด 5**
  - `RecipeSlot { ItemData item; bool anyOfCategory; ItemCategory category; }` (anyOfCategory = true → ใช้ category)
  - ช่อง `ingredients` เดิมเก็บไว้แบบ `[HideInInspector]` ให้ asset เก่าเปิดได้ ตัว import เขียน slots ใหม่ทั้งหมด (Claude)
- `MaxIngredients` 4 → 5 / `MaxDifficulty` 3 → 4
- เพิ่ม `baseRecipe` (RecipeData) ใช้กับ ★4
- `HasCategorySlot` / `CategorySlotIndex` (สูตร v2 มีช่องหมวดได้ไม่เกิน 1 ช่อง — ตัว import เตือนถ้ามีมากกว่า)

### 4.5 การเลือกวัตถุดิบ (IngredientChoice)
- ใหม่ `RecipeRequirements` (static) แทน `GetRequiredCounts()` ทุกจุด (CookingSession, DailyMenu, RecipeDatabase, RecipeBook, InventoryUI):
  - `Resolve(recipe, inventory, chosenItem)` → Dictionary<ItemData,int> ที่ต้องหัก
  - `GetCandidates(recipe, inventory)` → วัตถุดิบในหมวดที่มีอยู่ เรียงจำนวนมากสุดก่อน
  - `DefaultChoice(recipe, inventory)` = ตัวที่เลือกล่าสุดของสูตรนี้ ถ้ายังมี / ไม่งั้นตัวที่มีมากสุด (ผู้ใช้)
  - `GetMaxServings(recipe, inventory)` = รวมทุกตัวในหมวด (ใช้กับเมนูประจำวัน/ความพร้อม)
- **หน้าต่างทำอาหารนอกร้าน:** สูตรที่มีช่องหมวด แสดงแถบเลือกวัตถุดิบ (คลิก ‹ › หรือรายการ) ค่าเริ่มต้นตามด้านบน (ผู้ใช้)
- **ทำสดในร้าน (เตา):** ~~ใช้ตัวที่เลือกล่าสุดอัตโนมัติ ไม่เปิดถาม~~ → **(ผู้ใช้ 27 พ.ย.) ผู้เล่นเลือกเองได้:** แถบเหนือเตาแยกตัวเลือกต่อวัตถุดิบ (ตัวล่าสุดขึ้นก่อน แล้วตามจำนวนที่มี) ทุกสูตรที่มีช่องหมวด / ตัวเลือกเดียว = เริ่มทำทันที
- ตัวที่เลือกล่าสุดเก็บใน `RecipeBook` + เซฟ (recipeId → itemId)
- เมนูประจำวันจองวัตถุดิบ: จองแบบรวมหมวด (นับรวม) แล้วหักตัวจริงตอนทำ (Claude)

### 4.6 จานแยกแบบ (DishVariantRegistry)
- static/runtime: `GetOrCreate(recipe, slotItem)` → ItemData (สร้างด้วย `ScriptableObject.CreateInstance` ครั้งเดียวต่อแบบ เก็บใน Dictionary)
  - `itemId` = `<recipeId>__<slotItemId>` เช่น `jp_sushi__salmon` / `itemName` = "Sushi (Salmon)" / icon = ของจานแม่ / type Dish / ราคาและค่าพลังตาม 4.7
  - `VariantParent` (recipe) + `VariantIngredient` (item) เก็บไว้ในช่องใหม่ของ ItemData (runtime only)
- จานที่ไม่มีช่องหมวด = ใช้ไอเทมจานเดิม (ไม่มีแบบ)
- `ItemDatabase.GetById` ถ้าเจอ `__` แต่ไม่มีใน database → ถาม registry สร้างให้ (เซฟ/โหลดทำงานได้เอง)
- ลูกค้าจ่ายตามไอเทมที่ได้จริง (ราคาแบบ × ตัวคูณ) ไม่ใช่ราคาของสูตร
- ทำจานที่มีช่องหมวด → ได้ไอเทมแบบ / ทุกระบบ (กระเป๋า เมนู จานในมือ ลูกค้า กล่อง) ใช้ไอเทมแบบตามปกติ

### 4.7 ราคาและค่าพลัง
- **จานไม่มีช่องหมวด:** ใช้ราคา/ค่าพลังจากชีต (ผู้ใช้จูนเอง ห้ามคำนวณทับ)
- **จานแบบ (มีช่องหมวด):** ราคาชีตคิดจากค่าเฉลี่ยหมวดแล้ว → **ราคาแบบ = ราคาชีต + (ราคาวัตถุดิบจริง − ค่าเฉลี่ยหมวด) × 2.4 × ตัวคูณสูตร** (สูตรลับ ×1.3 / ★4 ×2.0) ปัด 5 / ค่าพลัง = ค่าชีต + (ค่าวัตถุดิบจริง − ค่าเฉลี่ย) × (H 1.5 / S 1.5 / M 1.2) × (สูตรลับ ×1.2) แล้วตัดเพดาน (H 80 หรือ ★4 100 / S 250 / M 150) (Claude — รักษาค่าที่ผู้ใช้จูนไว้ และตรงกับสูตรที่ตกลงกัน)
  - ค่าเฉลี่ยหมวดคิดจาก ItemDatabase ตอนเริ่มเกม (วัตถุดิบในหมวดนั้นทั้งหมด)
  - วัตถุดิบที่ทุกค่า 0 = H 5 / S 20 ตอนสุก / ค่าติดลบ = 0 (ตามที่ตกลง)
  - ค่าคงที่ทั้งหมดอยู่ใน `CookingSettings` หัวข้อ Economy ให้ผู้ใช้ปรับ
- **ตัวคูณราคาขาย ดาว × คุณภาพ** (แทน `SalesLedger.QualityMultiplier`): ตาราง 4 × 3 ใน CookingSettings

| | OK | Good | Perfect |
|---|---|---|---|
| ★1 | 1.00 | 1.10 | 1.25 |
| ★2 | 1.10 | 1.275 | 1.50 |
| ★3 | 1.20 | 1.45 | 1.75 |
| ★4 | 1.30 | 1.625 | 2.00 |

  - ใช้ที่: ขายตรงร้านของชำ, กล่องขาย, **ลูกค้าในร้านจ่าย = ราคาจาน × ตัวคูณ** (เปลี่ยนจากเดิมที่คุณภาพมีผลแค่ความพอใจ/ทิป) + ทิปเหมือนเดิม
  - ดาวของจานแบบ = ดาวของสูตรแม่
- **ค่าพลังตามคุณภาพ (ผู้ใช้ 26 พ.ย.):** ตอนกินจาน ค่า Health / Stamina / Mana × OK 1.00 / Good 1.15 / Perfect 1.30 (ค่าใน CookingSettings) / คูณหลังตัดเพดานจาน แล้วตัดที่เพดานผู้เล่นตามปกติ / FEVER ไม่คูณ (Claude) / วัตถุดิบดิบไม่มีคุณภาพ ไม่คูณ
  - เทียบกับ 1.25 / 1.50 แล้ว: ชุด 1.15 / 1.30 ไม่ทำให้จานกลางเกม Perfect เติมเต็มหลอดในจานเดียว (ดูตารางในแชท 26 พ.ย.)

### 4.8 UI: ช่องรวม + กางรายการ + กรอบไฮไลท์ (ผู้ใช้)
- **กระเป๋า แท็บ Dishes:** 1 ช่องต่อสูตร (รวมทุกแบบทุกคุณภาพ) / ไม่เคยทำสักแบบ = เหมือนเดิม (Undiscovered/ซ่อนสูตรลับ)
- **กล่องตอนวางเมาส์:** แสดงทุกแบบ × คุณภาพ (ต่อจาก DishQualityTooltip)
- **แผงรายละเอียด (คลิกช่อง):** รายการแถว "Salmon · Perfect ×1" ต่อแบบ × คุณภาพ ทุกแถวมีปุ่ม **Eat** และ **ลากลง Hotbar** ได้
- **Hotbar:** ช่องจำ itemId + คุณภาพ (จาน) / แถวนั้นหมด = ไอคอนสีเทา ช่องยังอยู่ (ผู้ใช้) / ของที่ไม่ใช่จานเหมือนเดิม
- **แผงขาย / กล่องขาย:** แถวแยกตามแบบ × คุณภาพ (ต่อจากที่แยกคุณภาพอยู่แล้ว)
- **ServePicker (เสิร์ฟลูกค้า):** ตัวเลือก = แบบ × คุณภาพ ที่มีในกระเป๋า/ในมือ / มีตัวเลือกเดียว = เสิร์ฟทันที (เหมือนเดิม)
- **กรอบไฮไลท์ตอนวางเมาส์ (ผู้ใช้):** ช่องกระเป๋าทุกแท็บ (วัตถุดิบ จาน และอื่นๆ ที่มีของ) + แถวแบบ × คุณภาพ ในแผงรายละเอียด ขึ้นกรอบเรืองบอกว่ากดได้
  - (Claude) ใช้แบบเดียวกันกับช่อง Hotbar, แถวแผงขาย/กล่องขาย และรายการในหน้าต่างทำอาหาร ให้ทั้งเกมเหมือนกัน / แยกจากกรอบ "เลือกอยู่" (SelectionFrame) ที่มีอยู่แล้ว
  - ช่องที่ทำอะไรไม่ได้ (ว่าง / ยังไม่ค้นพบ) ไม่ขึ้นกรอบ

## 6. งาน 3: Fine-dining แบบ Mastery (ผู้ใช้)
- **นับ:** ทุกครั้งที่ลูกค้าในร้านได้จาน (Customer.TryServe สำเร็จ) → `+1` ให้สูตรแม่ (รวมทุกแบบทุกคุณภาพ) / ทำในบ้าน กล่องขาย ไม่นับ / นับตั้งแต่ต้นเกม
- **เกณฑ์:** ดาวของสูตรต้นทาง ★1 = 400 / ★2 = 200 / ★3 = 100 (ค่าใน CookingSettings) + ร้านเลเวล ≥ 4
- **ปลด:** ตอนขึ้นวันใหม่หลังนอน (OnDayStarted) ถ้ามีสูตร ★4 ที่ถึงเกณฑ์และยังไม่รู้ → ปลด **คืนละ 1 สูตร** (Claude) เรียงตามเกณฑ์ครบก่อน → pop-up พิเศษ ("Fine dining Invention!" + ชื่อจาน) ขึ้นตอนเช้า → รู้สูตร ทำได้วันนั้นเลย (= วันถัดจากวันที่ครบ ตามที่ผู้ใช้ขอ)
  - ตอนนี้ pop-up เดียวทุกแบบ / cutscene (Story) จดหมายเชฟ (Chef) pop-up เทศกาล รอเฟส 3 (ข้อมูลแยกไว้ใน Obtain Note แล้ว)
- **บรรทัดความคืบหน้า:** ในแผงรายละเอียดจาน/สมุดสูตรของสูตรต้นทางที่รู้แล้ว: `Fine dining Invention : 15/100` + ไอคอนจาน ★4 เป็นเงาดำ + ตัวหนังสือพิเศษ (สีทองไล่เฉด TMP `<gradient>` หรือสีทอง + กะพริบเบาๆ) / ไม่บอกชื่อจาน ★4
  - ร้านยังไม่ถึง Lv4 แต่นับครบ: แสดง `x/y` เต็ม + "Shop Lv 4" (Claude)
