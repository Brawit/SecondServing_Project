# 2.6 แบบร่าง: เงิน + ชื่อเสียง + อัปเกรดร้านผ่านช่าง

> 24 พ.ย. 2026 · ต่อจาก 2.5c (ShopProgress / จดหมายเชฟ)

## 1. ทำไม

- ตอนนี้ลูกค้าจ่ายเป็นแค่สถิติรายวัน ผู้เล่นไม่มีเงินสะสม และราคาจานเป็น 0 ทุกจาน / ความพอใจลูกค้าคำนวณแล้วแต่ยังไม่ใช้
- ผู้ใช้อยากให้ร้านโตแบบ Stardew: **จ่ายเงิน (+ ของ) ให้ NPC ช่างในชนบทมาก่อสร้าง** ช่างรับงานหลายแบบ (ร้าน บ้าน ส่วนเสริม บ่อกุ้ง บ่อปลา เรือนกระจกที่ปลูกได้ทุกฤดู)
- อัปเกรดร้าน = เลเวลร้านขึ้น = ฟังก์ชันใหม่ / ผู้ใช้ต้องการให้ช้าพอ ไม่เคลียร์เนื้อหาร้านเร็ว และให้ผู้เล่นหาเงินทางอื่นด้วย (เช่น Stardew ตกปลารวยตั้งแต่ต้นเกม)
- ที่ตกลงไว้ก่อนหน้า: ความยาก + คุณภาพ + เมนูนิยม → ความพอใจ → เงิน + ชื่อเสียง / จานต้นเกมต้องขายได้จนจบเกม (ความยากไม่ขึ้นราคาโดยตรง)

## 2. เป้าหมาย / ไม่ทำ / ห้ามเกิด

**เป้าหมาย**: กระเป๋าเงิน (B = Baht) / ราคาวัตถุดิบ + จาน / ทิป / ชื่อเสียงแบบหลอดทีละเลเวล + ชื่อเสียงรวม / ระบบก่อสร้างกลาง + งานอัปเกรดร้าน 3 ขั้น / จุดช่างชั่วคราว + หน้าต่างก่อสร้าง / เงินบนจอ / หน้าสรุปวัน (เงิน ทิป ชื่อเสียง) / ของแนบเงินในจดหมาย / เซฟ v8

**ไม่ทำ**: NPC ช่างจริง (เฟส 3) / บ้าน บ่อ เรือนกระจก (เฟส 3 แค่เพิ่มไฟล์งาน + ผลลัพธ์ใหม่) / ซื้อ-ขายของในร้านค้า (2.6b) / ภาพนั่งร้าน (เฟส 4) / ปรับรอบขาย-ความถี่ลูกค้า (ช่วงเล่นทดสอบทั้งวงจร)

**ห้ามเกิด**: จานต้นเกมไม่มีค่า / หักเงินซ้ำหรือหักแล้วงานไม่เริ่ม / งานก่อสร้างหายหลังโหลด / ดองชื่อเสียงแล้วอัปรวดเดียว / จดหมายเชฟตกหล่น

## 3. ตัดสินแล้ว (ผู้ใช้)

- สกุลเงิน **B** (Baht) แสดง `B 1,250`
- **ชื่อเสียงแบบหลอด EXP ทีละเลเวล**: เต็มแล้วหยุด (ดองไม่ได้) / **อัปเกรดร้าน = หลอดกลับเป็น 0** / เก็บ **ชื่อเสียงรวมตลอดเกม** แยก (หน้าสรุป + งานครบรอบร้านเฟส 3)
- หลอด **500 → 1,500 → 3,000** / เงินอัปเกรด **20,000 → 75,000 → 150,000** / เลเวล 4 = สูงสุด (หลอด 3,000 ใช้เป็นเงื่อนไขจดหมายเท่านั้น)
- ก่อสร้าง **1–3 วันตามขนาดงาน เปิดร้านได้ปกติ** ระหว่างสร้าง
- ระบบช่างเป็นแบบกลาง (**ทาง B**: ไฟล์งานก่อสร้างแยก) 2.6 ทำจริงแค่อัปเกรดร้าน ใช้จุดชั่วคราวแทน NPC
- ราคา **ตามความหายากในเกม** ไม่อิงราคาจริง

## 4. ทางที่พิจารณา

- A ตารางเลเวลใน ShopProgress อย่างเดียว: เร็วสุด แต่เฟส 3 ต้องรื้อทำระบบช่างใหม่
- **B (เลือก) ไฟล์งานก่อสร้าง `ConstructionProject` + ShopProgress เก็บแค่ข้อมูลเลเวล + `ConstructionManager`**: งานใหม่เฟส 3 = ไฟล์ใหม่ + ผลลัพธ์ใหม่ ไม่รื้อ

## 5. เงิน

- `PlayerWallet` บน Player: `Money` (เริ่ม 500), `Add(amount)`, `TrySpend(amount)`, `CanAfford`, event `OnMoneyChanged` / Debug: `+1,000`, `+10,000`, `Reset`
- **ลูกค้าจ่าย = ราคาจาน + ทิป** เข้ากระเป๋าทันทีตอนได้อาหาร
  - ทิป = ปัดเศษ( ราคา × max(0, ความพอใจ − 0.9) ) → ชอบมาก ★1 ≈ +60% / อร่อยดี ★1 ≈ +10% / อร่อยดี ★3 ≈ +35% / เฉยๆ = 0 (ค่า 0.9 และตัวคูณทิปตั้งใน Inspector)
  - สถิติรายวันใน CustomerManager: `EarnedToday` (รวม) + `TipsToday`
- ของแนบ**เงิน**ในจดหมาย (`LetterAttachmentKind.Money` ต่อท้าย) รับ = เข้ากระเป๋า
- **เงินบนจอ** ใต้นาฬิกา `B 1,250` (ซ่อนพร้อมนาฬิกาตอนเปิดร้านไหม → ไม่ซ่อน แสดงตลอด เห็นเงินเข้าระหว่างขาย) [Claude ตัดสิน]

## 6. ราคา (Claude กรอกร่างแรกในตาราง ผู้ใช้ปรับได้)

- **วัตถุดิบ** ตามแหล่ง + ความหายาก: Forage 8–20 (ผลไม้/ดอกไม้หายากสูงกว่าผักทั่วไป) / Market 15–40 (เนื้อสัตว์สูงสุด) / Sea 35–70 / Artisan 40–90 (ของหมัก นม ชีส ของประจำชาติ)
- **จาน** = ปัดเป็นหลัก 5 ของ ( ผลรวมราคาวัตถุดิบหลัก × 1.6 + ค่าฐานตามประเภท (Main 20 / Dessert 15 / Drink 10) ) / สูตรลับ ×1.2 / ไม่ขึ้นกับความยาก
- ตัว import อ่าน `Sell Price` อยู่แล้วทั้งสองชีต → สร้าง CSV ใหม่ + import ซ้ำ

## 7. ชื่อเสียง (ShopProgress ปรับจาก 2.5c)

- ต่อลูกค้าที่ได้กิน: ชอบมาก **+3** / อร่อยดี **+2** / เฉยๆ **+1** / เดินออกเพราะรอนาน **0** (ไม่หัก)
- `Level` (1–4), `Reputation` (ในหลอดของเลเวลนี้ 0..BarSize เต็มแล้วหยุด), `LifetimeReputation` (นับทุกแต้มที่ได้ รวมตอนหลอดเต็ม), `BarSize`, `IsBarFull`, `BarSpent` (จ่ายหลอดเพื่อเริ่มอัปเกรดแล้ว รอสร้างเสร็จ)
- ตารางเลเวลใน Inspector (`levels`): ขนาดหลอด + โบนัสรวมของเลเวลนั้น
  | เลเวล | หลอด | ช่องเมนู | เมนูนิยม | โอกาสชอบมาก |
  |---|---|---|---|---|
  | 1 | 500 | +0 | +0 | +0 |
  | 2 | 1,500 | +1 | +0 | +0 |
  | 3 | 3,000 | +1 | +1 | +5% |
  | 4 | 3,000 (สูงสุด) | +2 | +1 | +10% |
- เลเวลเปลี่ยน / โหลดเซฟ = เรียก `DailyMenu.SetBonusSlots`, `PopularDishes.SetBonusCount`, `CustomerManager.SetLovedChanceBonus`
- **จดหมายเชฟ**: ถึงเกณฑ์เมื่อ `Level > n` หรือ (`Level == n` และ (`Reputation ≥ x` หรือ `BarSpent`)) → จดหมายของเลเวลที่ผ่านแล้วไม่ตกหล่น แม้หลอดรีเซ็ต
- **ตาราง Mail Reputation** กระจายใหม่ตามหลอด (Claude แก้): เลเวล 1 ช่วง 50–450 / เลเวล 2 ช่วง 150–1,300 / เลเวล 3 ช่วง 500–2,500 / เลเวล 4 ช่วง 1,000–2,500

## 8. ระบบก่อสร้าง

- **`ConstructionProject`** (ScriptableObject `Assets/Construction/`): `projectId`, `displayName`, `description`, `money`, `materials` (ItemData + จำนวน, ตอนนี้ว่าง), `days`, `requiredShopLevel` (เลเวลปัจจุบันต้องเท่านี้), `requiresFullReputation`, `effect` (enum `ConstructionEffect`: `ShopLevelUp` ต่อท้ายเท่านั้น เฟส 3: HouseUpgrade, FishPond, Greenhouse ...)
  - ไฟล์ตัวอย่าง: `shop_upgrade_2` (20,000 / 1 วัน / Lv1 / หลอดเต็ม), `shop_upgrade_3` (75,000 / 2 วัน / Lv2), `shop_upgrade_4` (150,000 / 3 วัน / Lv3)
- **`ConstructionManager`** (singleton): `projects` (รายการทั้งหมด), `Current`, `DaysLeft`, `IsBuilding`, `CanStart(project, out string reason)`, `TryStart(project)`, event `OnConstructionChanged`
  - เริ่ม: เช็กครบ → หักเงิน + ของ → ถ้า `requiresFullReputation` = หลอดกลับ 0 และตั้ง `BarSpent` → `DaysLeft = days` / สร้างได้ทีละงาน (แบบ Stardew)
  - ทุกเช้า (`OnDayStarted`): `DaysLeft--` → 0 = เสร็จ → ทำ effect (`ShopProgress.LevelUp()` → ล้าง `BarSpent`) + แจ้ง `Shop upgrade complete! Your shop is now level 2.`
  - เริ่มสร้างวันนี้ 1 วัน = เสร็จเช้าพรุ่งนี้
  - Debug: `Finish Construction Now`, `Print Status`
- **เคาน์เตอร์ช่าง `BuilderCounter`** (ผู้ใช้: ไปคุยกับช่างที่**เคาน์เตอร์ในบ้านช่าง** ไม่ใช่ป้าย / ระหว่างเปิดร้านออกจากร้านไม่ได้อยู่แล้ว): IInteractable `[E] Builder` → เปิด `ConstructionUI` / ตอนนี้ยังไม่มีบ้านช่าง = วัตถุเคาน์เตอร์ที่ผู้ใช้วางเองได้ ย้ายเข้าบ้านช่างตอนมีแผนที่จริง / เฟส 3 มี NPC ช่างยืนหลังเคาน์เตอร์
  - **เวลาทำการช่าง 09:00–16:00** นอกเวลา = `The builder's shop is closed.` (ตั้งใน Inspector) [Claude เสนอ ผู้ใช้ไม่ค้าน]
- **`ConstructionUI`** หน้าต่างกลางจอ (นาฬิกาหยุด ล็อกเดิน Esc ปิด):
  ```
  ┌ Builder ─────────────────────────────────┐
  │ Shop Level 1 → 2                          │
  │ Reputation  [██████████░░] 420 / 500      │
  │ Cost        B 20,000  (you have B 5,300)  │
  │ Time        1 day                         │
  │ Unlocks     +1 menu slot                  │
  │                         [Hire]  [Close]   │
  └───────────────────────────────────────────┘
  ```
  - ปุ่ม Hire กดได้เมื่อครบ ไม่ครบ = ข้อความบอกว่าขาดอะไร (สีแดง) / กำลังสร้าง = `Under construction · 2 days left` / เลเวลสูงสุด = `Your shop is fully upgraded.`
  - **กด Hire = กล่องถามยืนยัน Yes / No** (ผู้ใช้) เช่น `Upgrade your shop to level 2 for B 20,000? It will take 1 day.`

## 9. หน้าสรุปวัน (ทำส่วนหนึ่งของ 2.7)

**ทางขายของ (ทำจริงใน 2.6b):** A = ขายตรงกับ NPC ร้านค้า/ตลาด ได้เงินทันที / B = **กล่องขายข้ามคืนแบบ Stardew** (ผู้ใช้เลือกหลังคุยหลายทาง: ภูต ศาลเจ้าที่ รถพ่อค้าคนกลาง กล่องคุณยาย) ใส่ของเมื่อไหร่ก็ได้ ขายตามราคา เงินขึ้นใน**หน้าสรุปวัน** = ช่องทิ้งของที่ไม่ใช้แล้วด้วย / ยังไม่กำหนดเหตุผลในเรื่อง (เฟส 3 เติมได้) / C ขายออนไลน์ = ไม่เลือก
- หน้าสรุปแยกให้เห็นชัด: รายได้ร้าน (**ได้รับแล้ว** แค่สรุป ไม่บวกซ้ำ) / ขายจากตู้ข้ามคืน (**ได้รับตอนนี้** 2.6b) / รวมวันนี้
  ```
  Restaurant (already received)   B 1,240   (dishes 1,050 + tips 190)
  Shipping box (received now)     B   380   ← 2.6b
  Total today                     B 1,620
  ```
- 2.6 ทำโครง `DaySummaryData` ให้มีช่องรายได้ข้ามคืน (ตอนนี้ 0 ไม่แสดง) 2.6b แค่เติมค่า

`DaySummaryData` เพิ่ม: จานที่ขาย, ลูกค้า (ได้กิน / เดินออก), เงินจากร้าน (ราคา + ทิป), ชื่อเสียงที่ได้วันนี้, หลอด `Reputation 420 / 500`, เงินรวม / ไม่ได้เปิดร้าน = ไม่แสดงส่วนร้าน

## 13. ปรับหลังทดสอบรอบแรก (24 พ.ย.)

- เงินบนจอเป็น**ตัวเลขวิ่ง** (เข้า = ทอง / ออก = แดง)
- หน้าสรุปวัน: เมนู `Build Day Summary Layout` จัดใหม่ (พื้นเข้ม 900x660 เนื้อหาเต็มหน้าต่าง) ตัวจัด UI ห้ามกดหลังขัดเกลา
- **ช่างติดงาน = กด E ที่เคาน์เตอร์ไม่เปิดหน้าต่าง** ขึ้นข้อความว่ายุ่ง / จ้างเสร็จ = ปิดหน้าต่างเอง
- **ช่างเริ่มงานวันถัดไปหลังจ้าง**: จ้างวันที่ 1 งาน 1 วัน → เริ่มวันที่ 2 (แจ้งเตือน) → เสร็จเช้าวันที่ 3 / เซฟ `constructionStartsTomorrow`
