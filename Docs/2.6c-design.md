# 2.6c – ของป่าสำหรับสูตรเริ่มต้น + ไข่ในป่า (แบบร่างสั้น)

> 24 พ.ย. 2026 · คุยกับผู้ใช้แล้ว · ใช้ทดลองก่อน ขัดเกลาจริงตอนเฟส 3

## เป้าหมาย
- ของป่า 12 ชนิดที่ 8 สูตรเริ่มต้นใช้ (Source = Forage) เก็บได้จริงในแผนที่:
  มะละกอดิบ, มะเขือเทศ, พริก, ถั่วลิสง, มะม่วง, มะพร้าว, กะหล่ำปลี, โหระพา, เลมอน, ข้าวโพด, มะนาว, ผลไม้ตามฤดูกาล
- **ไข่ = ไข่ธรรมดา (`egg` ตัวเดียวกับใน Market)** ไม่ใช่ไอเทมพิเศษ แค่หาในป่าได้แต่ยากพอประมาณ (ผู้ใช้แก้ความเข้าใจผิดเรื่อง "ไข่หายาก")
- **ปริมาณแบบ B (ผู้ใช้เลือก):** เก็บของป่า 1 วัน ≈ พอ 1–2 เมนู ที่ขาดซื้อเติมที่ร้านของชำ (×2) หรือเลือกเมนูตามของที่เจอ
- พื้นที่ป่าสำหรับทดลอง **ไกลบ้านหน่อย** (ผู้ใช้ขอ)

## ไม่ทำ
- ไม่แก้ ForageItem / ForageSpawnZone / ForageSpawner (ระบบเดิมรองรับหลายชนิดต่อโซนแล้ว)
- ไม่เปลี่ยน Source ของไข่ในตาราง (ยังขายที่ร้านของชำ) / ไม่ทำภาพจริง / ไม่ทำฤดูกาล
- ไม่เพิ่มเวอร์ชันเซฟ

## ทางที่พิจารณา
1. **เมนู Tools เดียว `Build Forest Test Area`** (สร้าง prefab + ทาสีแผนที่ + สร้างโซน) ← **ผู้ใช้เลือก**
2. เมนูสร้าง prefab + โซน แต่ผู้ใช้ทาแผนที่เองด้วย Tile Palette (โค้ดน้อยกว่า แต่ทามือ ~600 ช่อง)
3. แก้ไฟล์ฉาก/prefab YAML บนดิสก์โดยตรง (ไม่ต้องกดใน Unity แต่ Tilemap พังง่าย + เสี่ยงโดน Save ทับ)

## แผนที่ (ป่าอยู่ด้านล่างบ้าน — ผู้ใช้รับข้อเสนอ)
- ลานเดิม: พื้น x −8..8, y −8..6 กำแพงที่ x = ±9, y = 7 และ y = −9
- **เจาะกำแพงล่าง** y = −9 ช่อง x −2..2
- **ทุ่งหญ้า/ทางเดิน** x −8..8, y −10..−28 (กว้างเท่าลาน กล้องจึงไม่แตกเป็น 2 เกาะ) กำแพงข้าง x = ±9 / ทางดิน (Dirt) กว้าง 2 ช่องตรงกลาง x −1..0 จาก y −9 ลงไปถึง y −32
- **ป่า** x −15..14, y −30..−49 (30 × 20 กว้างกว่าจอ กล้องเลื่อนได้) กำแพงรอบ x = −16, x = 15, y = −50 และแถวบน y = −29 เฉพาะ x −16..−9 กับ 9..15
- CameraBoundsMap ทา Bound ครอบลาน + ทุ่งหญ้า (รวมแถว y = −9) + ป่า ให้ต่อกันเป็นก้อนเดียว
- พิกัดในเครื่องมือเป็นค่าคงที่ปรับได้ที่หัวไฟล์ / ไม่ชนห้องในร้าน (x −102..−51)

## โซน (แบ่งตามลักษณะพื้นที่ — ผู้ใช้โอเค)
| โซน | ตำแหน่ง | ของ (น้ำหนัก) | สูงสุด / เริ่ม / งอกต่อวัน / โอกาส |
|---|---|---|---|
| `Zone_Field` ทุ่งผัก | ป่าซ้ายบน ใกล้ทางเข้า | พริก 2, มะเขือเทศ 1.5, ถั่วลิสง 1.5, กะหล่ำปลี 1, ข้าวโพด 1, โหระพา 1 | 12 / 8 / 7 / 0.8 |
| `Zone_Orchard` สวนผลไม้ | ป่าขวาบน | มะม่วง, มะพร้าว, เลมอน, มะนาว, มะละกอดิบ, ผลไม้ตามฤดูกาล (1 เท่ากัน) | 12 / 8 / 7 / 0.8 |
| `Zone_MushroomForest` (เดิม ย้ายมา) | ป่าลึกด้านล่าง | เห็ด | ค่าเดิม |
| `Zone_EggNest` | มุมขวาล่าง ไกลบ้านที่สุด | ไข่ | **2 / 1 / 1 / 0.4** (≈ 1 ฟองต่อ 2–3 วัน, ผู้ใช้เลือก A) |

- รวม 2 โซนหลัก ≈ 10–12 ชิ้นต่อวัน
- `Zone_CornForest` เดิม = **ปิด (SetActive false)** ไม่ลบ ผู้ใช้ลบเองได้ / ของบนพื้นในเซฟเก่าของโซนนี้ถูกข้ามพร้อมคำเตือน (ไม่พัง)

## Prefab
- 13 ชิ้นใน `Assets/Prefabs/Forage/Pickup_<itemId>.prefab` โคลนจาก `Corn_Pickup` (SpriteRenderer + CircleCollider2D Trigger + ForageItem) เปลี่ยนสีให้แยกกันได้ + ผูก ItemData ตาม itemId (หาจาก AssetDatabase)
- `Corn_Pickup` / `Mushroom_Pickup` เดิมไม่แตะ (เห็ดยังใช้ `Mushroom_Pickup`)

## พฤติกรรมเครื่องมือ (กดซ้ำได้)
- prefab ที่มีแล้ว = kept / โซนที่มีชื่อนี้แล้ว = kept (ไม่ทับค่าที่ผู้ใช้จูน) / ทาสี tile ซ้ำได้ผลเท่าเดิม / ทุกอย่างผ่าน Undo
- หา Tilemap จากชื่อ `Ground`, `Obstables`, `CameraBoundsMap` / tile จาก `Assets/Tiles/Grass|Dirt|Wall|Bound.asset`
- หลังกด: บันทึกฉาก (Ctrl+S) + ItemDatabase → Find All Items (ไข่/ของป่าเป็นไอเทมเดิม ไม่จำเป็นแต่กันพลาด)
