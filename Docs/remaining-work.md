- ⬜ ปลูกพืช (Crop) + ต้นผลไม้ (Fruit Tree)
- ⬜ เลี้ยงสัตว์ (วัว แพะ ควาย เป็ด ไก่ นกกระทา) → นม / ไข่
- ⬜ เครื่องแปรรูป: เครื่องทำชีส (ชีส ชีสนมแพะ มอซซาเรลลา) / ถังบ่ม (พาร์เมซาน) / อื่นๆ (เนย โยเกิร์ต แป้ง เต้าหู้ พริกแกง ฯลฯ)
- ⬜ ของนำเข้า → ผลิตเอง: ใบชา→มัทฉะ, โกโก้→ช็อกโกแลต, วานิลลา, หญ้าฝรั่น, วาซาบิ, อินทผลัม, เมเปิล, พีแคน, กาแฟ
- ⬜ ทะเล + ตกปลา + Crab Pot / ของชายหาด
- ⬜ ระบบต่อสู้ + มอนสเตอร์ + บอส + ถ้ำ (8–12 สัปดาห์) → Monster Loot (เนื้อ สไลม์ ฯลฯ)
- ⬜ ความชำนาญอาวุธแบบ Stardew (แหล่งฟื้น Mana) / ความชำนาญทุกระบบ
- ⬜ สิ่งประดิษฐ์ไฮเทค (เตาอัตโนมัติ เครื่องรดน้ำ เครื่องพรวนดิน) + ฟีเจอร์คอมบนโต๊ะ
