# สูตรอาหาร + วัตถุดิบชุดใหม่ (Recipes v2) – แบบร่าง

> 26 พ.ย. 2026 · คุยกับผู้ใช้แล้ว · ส่วนนี้ = **ข้อมูลเท่านั้น** (โค้ดช่องหมวด + ตัว import เป็นแบบร่างแยกทีหลัง)

## ทำไม
- ผู้ใช้เล่นทดสอบทั้งวงจร 5 วัน: ทำได้แค่เลมอนเนด + จานหลัก 1 จาน เพราะสูตรเริ่มต้นใช้วัตถุดิบ 3–4 อย่าง (ส้มตำใช้ของป่า 4 ชนิด)
- สูตรเดิม 87: ใช้ 1 อย่าง 6 / 2 อย่าง 10 / 3 อย่าง 17 / 4 อย่าง 54 · จานหลักที่ใช้ 1–2 อย่างมีแค่บาร์บีคิวริบส์ (ได้จากบอส)
- วัตถุดิบเดิม 83 ชนิด หลายชนิดใช้สูตรเดียว / `seasonal_fruit` เป็นไอเทมเดียวที่รวมผลไม้หลายอย่าง ใช้ผลไม้อื่นแทนไม่ได้
- **เป้าหมาย:** ต้นเกมหาของเองแล้วทำได้หลายเมนูทุกคืน / เกมยังมีของให้ไล่หาถึงท้ายเกม

## ตัดสินแล้ว (ผู้ใช้)
- **คิดใหม่ทั้งหมด** ทั้งรายชื่อจานและวัตถุดิบ (ไม่ผูกกับชื่อจานเดิม)
- **74 สูตร** = 6 ชาติ (ไทย ญี่ปุ่น จีน อิตาลี อเมริกา เม็กซิโก) × 12 + House Special 2
- แบ่งตามจำนวนวัตถุดิบหลัก: **1 อย่าง 12 (ชาติละ 2) / 2 อย่าง 24 (ชาติละ 4) / 3 อย่าง 22 / 4 อย่าง 16**
- สูตรเริ่มต้น 10–12 สูตร จากกลุ่ม 1–2 อย่าง ทุกชาติมีจานหลักง่ายๆ อย่างน้อย 1 จาน
- **วัตถุดิบคิดใหม่** เป้า ~55–65 ชนิด แต่ละชนิดใช้ได้ ≥ 2–3 สูตร
- **7 แหล่ง:** ป่า (Forage) / สวน-ไร่ (Garden) / ทะเล (Sea) / ฟาร์มสัตว์ (Ranch) / ล่า-มอนสเตอร์ (Hunt) / แปรรูป (Processed) / นำเข้า (Import)
  - ร้านของชำ = ทางลัดซื้อเวลา (×2) ไม่ใช่แหล่ง / เครื่องปรุงพื้นฐาน = ตู้กับข้าว ไม่จำกัด ไม่เป็นไอเทม
- **ต้นเกม (ผู้ใช้):** ป่า + **ทะเล** (ตกปลาได้ตั้งแต่ต้น ไม่มีอุปสรรค) / ตอนนี้ยังไม่มีระบบตกปลา → ซื้อที่ร้าน + โซนเก็บของริมหาด (ForageSpawnZone เดิม)
- **ช่องหมวด "อะไรก็ได้" 3 หมวด (ผู้ใช้เลือก B):** ปลา / ผลไม้ / ผัก — ใช้มากในสูตร 1–2 อย่าง / สูตร 3–4 อย่างใช้ของเจาะจง / เนื้อสัตว์และไข่ไม่เป็นหมวด
- **สูตรลับ 12:** เก็บ 11 สูตรเดิม (ชื่อ + เรื่องราว) ปรับวัตถุดิบเข้าระบบใหม่ / **Grandma's Secret Tea → Father's Secret Grilled Chicken**
  - House Special · Main · Story · **เนื้อไก่ + ข้าวเหนียว** (น้ำตาล ซีอิ๊ว พริกไทยดำ ผงปรุงรส = ตู้กับข้าว)
  - ผู้ใช้: ไก่ย่างที่พ่อของผู้ใช้ขายที่ร้าน ขายคู่ข้าวเหนียว ไม่มีอะไรพิเศษ / แก่นเรื่อง = "ไม่มีสูตรลับ ความพิเศษอยู่ที่คนเชื่อว่ามันพิเศษ" (ได้แรงบันดาลใจจากกังฟูแพนด้า → **เขียนข้อความเป็นคำของเราเอง ไม่ยกประโยคหนัง**)
  - ฉากได้สูตร / ความทรงจำ = **เขียนร่วมกับผู้ใช้ตอนเฟส 3** (Claude ไม่แต่งเรื่องพ่อเอง)

## ทางที่พิจารณา
1. **ข้อมูลก่อน แล้วค่อยโค้ด** (ชีตใหม่ให้รีวิว → โค้ดทีเดียว) ← **ผู้ใช้เลือก**
2. โค้ดก่อน แล้วค่อยข้อมูล (ได้ลองระบบเร็ว เสี่ยงข้อมูลต้องการสิ่งที่โค้ดไม่รองรับ)
3. ทำคู่กันทีละชาติ (เห็นผลเร็ว แต่สมดุลวัตถุดิบข้ามชาติยาก)

## ความยาก + ราคาตามวัตถุดิบจริง (ตัดสินแล้ว 26 พ.ย.)
- **ความยาก (Difficulty ★1–3) กรอกใหม่ตามวิธีทำจริง** ไม่ใช่ตามจำนวนวัตถุดิบ (★1 24 / ★2 35 / ★3 15) เหตุผลอยู่ในคอลัมน์ Difficulty Note
- **ผู้ใช้: ความยากต้องมีผลกับราคา** (เปลี่ยนจาก 2.6b ที่เคยตัดสินว่าไม่เอา) / ผู้ใช้ยอมรับว่าจานแพงท้ายเกมได้เงินเยอะ (เทียบ Stardew starfruit) มีของให้ใช้เงินเยอะ
- **ตัวคูณราคาสุดท้าย = ตัวคูณคุณภาพ + โบนัสดาวคงที่ + โบนัสดาวตามคุณภาพ** (บวกกัน ไม่คูณกัน) ใช้ทั้งในร้าน กล่องขาย และร้านของชำ (ในร้านบวกทิปตามความพอใจเพิ่ม)

  | | OK | Good | Perfect |
  |---|---|---|---|
  | ★1 | ×1.00 | ×1.10 | ×1.25 |
  | ★2 | ×1.10 | ×1.275 | ×1.50 |
  | ★3 | ×1.20 | ×1.45 | ×1.75 |

  - คุณภาพ OK 1.0 / Good 1.1 / Perfect 1.25 (เดิม) · ดาวคงที่ ★2 +10% / ★3 +20% (ผู้ใช้) · ดาวตามคุณภาพ ★2 Good +7.5% Perfect +15% / ★3 Good +15% Perfect +30%
  - ทุกตัวเลขเก็บใน CookingSettings ให้ผู้ใช้ปรับ
  - **เปลี่ยนจากเดิม:** ในร้านลูกค้าจ่ายตามตัวคูณนี้ด้วย (เดิมคุณภาพมีผลแค่ความพอใจ/ทิป)
- **ราคาตามวัตถุดิบที่ใช้จริง (ผู้ใช้เลือก)** จานที่ใช้ช่องหมวด คิดราคาตอนทำด้วยสูตรเดียวกันจากราคาวัตถุดิบจริง (ซูชิปลานิล 205 / แซลมอน 350) / Sell Price ในตาราง = ราคาอ้างอิง (ค่าเฉลี่ยหมวด) ใช้ในสมุดสูตรและราคาสมุด ×10
  - จานแสดงชื่อพร้อมวัตถุดิบ เช่น "Sushi (Salmon)" / แยกกองในกระเป๋าตาม จาน + วัตถุดิบหมวด + คุณภาพ / กระทบ: กระเป๋า เซฟ ราคาในร้าน กล่องขาย ร้านค้า การจองวัตถุดิบในเมนูประจำวัน
- **เลือกวัตถุดิบในช่องหมวด = ผู้เล่นเลือกเองในหน้าต่างทำอาหาร (ผู้ใช้)** ค่าเริ่มต้น = ตัวที่มีมากที่สุด / ตอนเปิดร้าน (ทำสด) ใช้ตัวที่เลือกล่าสุดของจานนั้น
  - เหตุผล: Stardew ไม่ให้เลือก (ไล่ตามลำดับช่อง) คนบ่นว่าเสียปลาหายาก + กระเป๋าเราไม่มีช่องให้จัด

## Stamina แบบ Stardew (ตัดสินแล้ว 26 พ.ย.)
- **ผู้ใช้: ฟื้นเองตอนเดิน/ยืนเฉยแปลก (เดิมฟื้น 10/วิ หลังพัก 1.5 วิ = ~10 วิเต็ม อาหารไม่มีความหมาย) → ใช้แบบ Stardew**
  - **ไม่ฟื้นเอง** ฟื้นได้จาก อาหาร/วัตถุดิบกินได้ + นอน (เฟส 3 อาจเพิ่มบ่อน้ำร้อน/จุดพัก แบบ Spa ของ Stardew / Coral Island)
  - ใช้กับเครื่องมือ / **อาวุธไม่ใช้ Stamina (แบบ Stardew)** / **วิ่งไม่ใช้ Stamina (แบบ Stardew)** — Claude ตัดสินตามคำว่า "เหมือน Stardew" ผู้ใช้แก้ได้
  - **เพดานเริ่มเกม (ผู้ใช้กำหนด): Health 100 / Stamina 250 / Mana 200** (เดิม 100 / 100 / 50)

## ฤดูกาล + ประเภทวัตถุดิบ + วัตถุดิบเพิ่ม (ตัดสินแล้ว 26 พ.ย.)

- **ต้องตัดสิน:** สูตรเริ่มต้นใช้ของตามฤดู (พริก Summer, มันฝรั่ง Spring, เลมอน Winter, ข้าวโพด Summer/Fall) → Claude เสนอ: ร้านของชำขายของ `In Store = Y` ได้ทั้งปี (×2) ต้นเกมจึงทำสูตรเริ่มต้นได้ทุกฤดู แต่ของฟรีจากป่า/ทะเลขึ้นตามฤดู
